> ### АНТИВИРУСЫ И WinDivert
> Антивирус может отреагировать на WinDivert.  
> Это компонент для перехвата и фильтрации трафика, без которого zapret не работает.
> Один и тот же инструмент способны использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Часть антивирусов относит WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и помещается в карантин. В обнаружении обязательно встречается `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете, как работают исключения, лучше настроить исключение для каталога. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от варианта "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS в настройках самой системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
   * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/FairFlyChant/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить.

4. Извлеките файлы в путь, где нет кириллических символов и специальных знаков.

5. Запустите подходящий файл.
   * Чтобы определить работающую стратегию, откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
   * Для запуска стратегии вместе с системой выберите **`service.bat`** → `Install Service` → нужная стратегия.

## ℹ️ Назначение основных файлов и пунктов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) — автозапуск, диагностика, тестирование и другие операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (`services.msc`).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и прочих сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения настройки стратегию нужно перезапустить.**  
  В скобках показывается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — выбрать режим обработки сервисов из `ipset-all.txt`.  
  Этот пункт полезен при диагностике ресурса, который без zapret работает, а с ним — нет.  
  Возможные значения:
    - `none` — IP-адреса не проверяются;
    - `loaded` — адреса проверяются на присутствие в списке;
    - `any` — под фильтр попадает любой IP-адрес.  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало работать.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через `service`, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/FairFlyChant/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

1. Запустите командную строку с правами администратора.
2. Выполните команды по очереди:

   `netsh winsock reset`

   `netsh int ip reset all`

   `netsh winhttp reset proxy`

   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
- скопируйте весь текст из открытого блокнота;
- откройте файл `hosts` в появившейся папке через текстовый редактор, запущенный от имени администратора;
- вставьте скопированное в конец файла `hosts` или замените ранее добавленный аналогичный фрагмент;
- сохраните файл и снова проверьте подключение. Если результат не изменился, убедитесь, что hosts действительно сохранился.

#### Работа не гарантируется. Если инструкция не помогла, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/FairFlyChant/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или прекратил работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> После обнаружения определённая стратегия может перестать работать, даже если до этого некоторое время всё было нормально.
> В репозитории собрано много вариантов обхода. Если готовые стратегии не помогают, создайте новую на основе одной из них и измените параметры. Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте `service.bat` → `Run Diagnostics` и устраните найденные ошибки.
- Убедитесь, что адрес нужного ресурса включён в списки доменов или IP-адресов.
- Испытайте другие варианты, в том числе **`ALT`** и **`FAKE`**.
- При необходимости выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/FairFlyChant/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните добавленные вами ресурсы и другие нужные данные.
- Перезагрузите устройство.
- В `service.bat` выберите `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите `Y`.
- Удалите каталог zapret.
- Скачайте последнюю версию со [страницы релизов](https://github.com/FairFlyChant/zapret-discord-youtube/releases) — архив с именем `zapret-discord-youtube-...`.
- Нажмите по архиву правой кнопкой мыши и откройте свойства. Если внизу есть флажок разблокировки, включите его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новую папку в корне диска. В пути не должно быть пробелов и специальных символов.
- Запускайте разные скрипты `general`, проверяя доступ к интернет-ресурсам. Если выбранная стратегия не подходит, закройте программу через значок замка на панели задач и попробуйте следующую.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` → `Install Service`.

### Игра или приложение не работает при включённом zapret

Проверьте в `service.bat`, что **`Game Filter` имеет значение `disabled`**, а **`IPSet Filter` — `none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не планировали обходить.

### Античит обнаруживает WinDivert

Инструкция по этому случаю находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы в командной строке Windows. Откройте `Win+R`, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив полученное на первом шаге имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS включён](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Испытайте все остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/FairFlyChant/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS настроен](#%EF%B8%8F-использование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` перейдите в `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте приложение Discord, помогла ли очистка.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если сайт также не открывается, последовательно проверьте остальные стратегии. YouTube и Discord могут работать на разных стратегиях.
- Дополнительные сведения: [#252](https://github.com/FairFlyChant/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/FairFlyChant/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учитывайте, что `ipset any` способен нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/FairFlyChant/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

Создайте обращение [здесь](https://github.com/FairFlyChant/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Списки обхода можно расширить вручную:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, это пригодится, если сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не следует;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** будут автоматически созданы при первом запуске `zapret` или `service.bat`.
